## 🚀 Features

### 🎯 F2 Mode - Written QAs

1. ⌘C: Copy any written question 

2. F2: To send question to ChatGPT

>  Answer arrives back straight to your clipboard

3. ⌘V: to paste your retrieved answer


> No browser switching. No suspicious activity. Like a ghost with a degree.


---

### 🎯 F1 Mode - MCQs (only Mac)

1. ⌘C: Copy a multiple-choice question

2. F2: To send question to ChatGPT

3. Answer discreetly appears in the menu bar 

> Zero pop-ups. Zero windows. Zero eyes.

> Perfect for scenarios where screens are... occasionally supervised.
